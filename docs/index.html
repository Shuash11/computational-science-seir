Browser port of the Python SEIRV pipeline (seir_model.py, RK45) - reimplemented in JavaScript (RK4, step 0.02 day) and validated against the pipeline output. Scenario presets reproduce the project's five policies with the calibrated transmission rate beta0 = 0.4409 (R0 = 2.205 on the demo grid; fitted value 2.2045), population 500,000, latent period 3 days, infectious period 5 days.
